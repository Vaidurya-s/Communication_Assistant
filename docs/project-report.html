02 The Solution

A communication memory
layer for the professional web.

Comms Assistant is a Chrome extension that lives inside LinkedIn and Gmail — where the work already happens. It does three things no existing tool does together: it learns your writing voice, it remembers every professional relationship, and it drafts context-aware replies that sound exactly like you.

1
It reads the conversation
The extension's content script extracts the live thread from LinkedIn or Gmail — participant names, message history, tone, intent — without the user copying or pasting anything.
2
It knows who you're talking to
A persistent SQLite memory layer stores everything known about this contact: past interactions, confirmed notes, relationship strategies, follow-up commitments. Context that would otherwise live in your head — or be forgotten.
3
It drafts in your voice
A one-time voice profile distillation — trained on your own past messages — gives the LLM a precise style guide. Not a generic tone selector. Your actual patterns, vocabulary, and rhythm.
4
It learns over time
Every confirmed note, edited draft, and piece of feedback refines the system. The assistant gets sharper with each interaction — not static, always improving.
